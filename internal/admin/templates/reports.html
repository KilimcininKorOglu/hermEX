Reports

Reports other mail servers send to a hosted domain's postmaster address: DMARC aggregate reports, TLS reports (RFC 8460) and DMARC failure reports. A report is stored only for the domain it was addressed to. A system administrator sees every domain's reports, a domain administrator only their domains'.

Reports are deleted once they are older than their retention window, counted from the time they arrived. 0 keeps them forever. A failure report carries the failed message's headers, which are personal data, so keep it for a shorter time.

When this is on, the server counts the mail it receives from each domain that asks for DMARC aggregate reports, and once a day sends that domain a report to the mailto: addresses its DMARC record names. A report lists the addresses that sent mail claiming the domain, and how each one authenticated. It is sent from noreply at the server's hostname, and it is DKIM-signed only when that hostname has a DKIM key.
